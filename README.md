# Excel Edge Academy

A modern, responsive website for Excel Edge Academy, India's trusted coaching institute for IIT-JEE, NEET, Boards, and Foundation courses.

## 🚀 Features

- **Modern UI**: Built with React, TypeScript, and Tailwind CSS
- **Responsive Design**: Optimized for all devices
- **Fast Performance**: Powered by Vite for lightning-fast builds
- **Interactive Components**: Custom animations and UI components
- **SEO Optimized**: Meta tags and structured content
- **Course Management**: Detailed course information and enrollment

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS v4
- **Build Tool**: Vite
- **UI Components**: Radix UI, Lucide Icons
- **Animations**: Framer Motion
- **Package Manager**: Bun

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/excel-edge-academy.git
   cd excel-edge-academy
   ```

2. Install dependencies:
   ```bash
   bun install
   ```

3. Start the development server:
   ```bash
   bun run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🏗️ Build for Production

```bash
bun run build
```

The built files will be in the `dist/` directory.

## 🚀 Deployment

### Vercel

1. Connect your GitHub repository to Vercel
2. Vercel will automatically detect the Vite configuration
3. Deploy with default settings

### Other Platforms

The build output in `dist/` can be deployed to any static hosting service like Netlify, GitHub Pages, etc.
