# Excel Edge Academy

A responsive education portfolio presenting programs, course details, faculty, results, admissions, academy information, and contact content.

**Live website:** [exceledgeacademy.vercel.app](https://exceledgeacademy.vercel.app/)  
**Repository:** [GrowthXCircle/academy-website](https://github.com/GrowthXCircle/academy-website)

## Highlights

- Home, courses, course-detail, faculty, results, admissions, about, and contact routes
- Responsive shared layout
- Animated counters, particles, cursor effects, and scroll progress
- Typed React components

## Technology

React 19, TypeScript, TanStack Router, TanStack Start, Vite 7, Tailwind CSS 4, Framer Motion, and Lucide React.

## Local development

Node.js 22 or newer and npm are recommended.

```bash
git clone https://github.com/GrowthXCircle/academy-website.git
cd academy-website
npm install
npm run dev
```

Create and preview a production build:

```bash
npm run build
npm run preview
```

Run the configured linter with `npm run lint`.

## Project scope

This is a frontend demonstration project, not the website of an operating business. Courses, faculty profiles, results, admissions information, statistics, and contact details are illustrative.
